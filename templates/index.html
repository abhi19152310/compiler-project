Supported sentence guide

Ordinary English

Create a web page called Abhishek.Build me a website named Techno Fest.Add a green navbar with Home, About and Contact.Add a Register button below the navbar.Make the button rounded.

Offline English covers common patterns. Configure Ollama for model-assisted paraphrases. Images still need a real source and description; ambiguous targets need clarification.

Start with a page title

Create a page titled "Techno Fest".

Add content

Add a big heading that says "Techno 2026".Add a paragraph that says "Welcome".Add a blue button that says "Register".Add an image "stage.png" described as "Main stage".Make it bold.Make it Arial.Put it to the left of the heading.

Build complete pages

Create a navigation bar with Home, About and Contact links.Create a main named "content".Create a link labelled "Visit GitHub" to "https://github.com" inside "content".Create three cards for Web Development, AI and Cloud Computing.Put all the cards inside one container.Stack the cards vertically on mobile.Give all cards consistent spacing and rounded corners.Create a contact form with name, email and message fields.Make the email field required.Set the heading font-size to 32 pixels.

Supported options

Elements: heading, paragraph, button, image, link, header, nav, main, section, footer, aside, container, card, lists, tables and static forms. Sizes: small, medium, big. Colors: blue, red, green, yellow, orange, purple, black, white. Put size before color.

"Add", "create", and "insert" are equivalent. "It" and "this" refer to the last introduced element. Position images or other elements left, right, above, or below the latest matching element type. Use named elements and "inside" for nesting. Supply actual list items, descriptions and dropdown options; missing content produces an error.

Defaults: rounded corners are 12px; card spacing is 24px; mobile stacking starts at 640px. The full property whitelist and English patterns are documented in docs/LANGUAGE.md in the project.

Images need a description unless explicitly decorative. Selected solid-color checks warn when text falls below the 4.5:1 contrast minimum; the page is still generated. This is not a complete accessibility audit. Navigation links use real destinations. Forms are static inert previews with disabled submit buttons; submission, authentication and storage are not connected. Generated action buttons are visual only.
